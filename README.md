# 🍎 사과게임

숫자가 적힌 사과를 드래그해 수확하는 10의 배수 게임입니다. 60초 동안 보드에서 합이 10의 배수가 되는 사과들을 찾아 점수를 올려 보세요.

## 게임 소개

- 8×8 보드에 1부터 9까지의 숫자 사과가 나타납니다.
- 시작 버튼을 눌러 게임을 시작한 뒤, 보드에서 드래그해 사각형 영역을 선택합니다.
- 선택한 사과 숫자의 합이 10의 배수이면 사과를 수확하고, 수확한 개수만큼 점수를 얻습니다.
- 수확한 사과 위쪽의 사과는 아래로 내려오며, 비어 있는 칸은 새 사과로 채워집니다.
- 최고 점수는 브라우저에 저장되며, 최고 기록을 갱신하면 컨페티 효과가 나타납니다.

## 어떻게 만들었나요

HTML로 게임 화면을 구성하고 CSS로 보드와 사과, 선택 효과를 꾸몄습니다. Vanilla JavaScript로 숫자 보드 생성, 드래그 선택과 합계 판정, 타이머, 점수 저장, 사과 낙하 및 컨페티 효과를 구현했습니다. Copilot Agent와 함께 기본 게임을 만들고 실행 결과를 확인하며 시작 방식과 수확 후 보드 동작 등을 다듬었습니다.

## 실행 방법

저장소를 내려받은 뒤 `index.html` 파일을 브라우저에서 열면 바로 플레이할 수 있습니다. 별도의 설치나 빌드 과정은 필요하지 않습니다.

## 커스터마이징한 부분

- 게임 시작 버튼을 눌러야 타이머가 시작되도록 변경했습니다.
- 숫자를 사과 아이콘 위에 표시해 게임 테마를 살렸습니다.
- 수확 후 빈칸이 남지 않도록 각 열의 사과가 내려오고 위쪽에 새 사과가 생성되게 했습니다.
- 최고 점수 갱신 시 화면에 컨페티 애니메이션을 추가했습니다.
- 최고 점수는 브라우저의 `localStorage`에 보관합니다.
